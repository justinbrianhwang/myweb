01 Introduction to Overleaf

What LaTeX and Overleaf are — and why academia depends on them.

What is LaTeX?

LaTeX is a professional typesetting language built on top of Donald Knuth's TeX system. Unlike WYSIWYG editors such as Word, you describe your document's structure with a markup language and a compiler produces a polished PDF.

What is Overleaf?

Overleaf is a cloud-based collaborative LaTeX editor. No installation required — write, compile, and collaborate directly in your browser. overleaf.com

Working in Overleaf feels like coding: the source editor sits on the left and the compiled PDF on the right. Edit the source, press Recompile (or Ctrl + Enter), and the PDF updates.

Compilation Flow

User source (.tex) │ ▼ LaTeX Compiler (pdfLaTeX / XeLaTeX / LuaLaTeX) │ ▼ PDF Output
Why LaTeX? Unmatched equation quality, automated cross-references / numbering / bibliography, and consistent output. Most conference and journal templates are LaTeX-based, making it the academic standard.

03 Document Skeleton

Preamble vs. Document body — the bones of every LaTeX document.

% --- Preamble (configuration area) ---
\documentclass{article}
\usepackage{graphicx}     % figure inclusion
\usepackage{amsmath}      % math environments
\usepackage{hyperref}     % hyperlinks / cross-references

% --- Document Body (actual content) ---
\begin{document}

  % write your content here

\end{document}
The Preamble is not printed. It is where you declare the class, load packages, define macros, and set metadata. All visible content must live between \begin{document} and \end{document}.

Try it: your first compile

The smallest document that compiles is a class plus a document body. Paste this into a new project and recompile:

\documentclass{article}
\begin{document}
Hello world!
\end{document}

To force a page break anywhere in the body, use \newpage.

Note: If you forget \maketitle, nothing will be printed even if you declared \title / \author.

Putting the header together

Declare the title block in the preamble, print it with \maketitle, then add the abstract and the first section (both covered next). \date{\today} prints today's date; an empty \date{} prints none.

\documentclass{article}
\title{My First Document}
\author{Sunjun Hwang}
\date{\today}

\begin{document}
\maketitle
\begin{abstract}
This is a short abstract of the document.
\end{abstract}
\section{Introduction}
Hello, world.
\end{document}

Want the title on a page of its own? Add the class option: \documentclass[titlepage]{article}.

Abstract

The class changes how sections look

The same source looks different under a different class. Switch article to book and recompile:

\documentclass{book}
\title{Sunjun's Paper}
\author{Sunjun Hwang}
\date{\today}
\begin{document}
\maketitle
\section{Introduction}
This is going to be a normal paragraph.
\end{document}

Each class has its own conventions, so check the output whenever you switch — and for a paper, use the venue's template class.

Subsections and sub-subsections

Papers often need “1.1”-style headings. \subsection adds one level:

\subsection{Some Background}
Text of the subsection...

One level deeper is \subsubsection:

\subsubsection{Drilled Down}
Text of the sub-subsection...
Unnumbered sections: Append * like \section*{Acknowledgments} to suppress both numbering and TOC inclusion.

07 Label & Reference

Automatic in-document cross-referencing — one of LaTeX's greatest strengths.

\section{Introduction}\label{sec:intro}

As shown in Section \ref{sec:method}, ...

See Figure \ref{fig:overview} and Equation \eqref{eq:main}.

Label Prefix Convention

TypePrefixExample
Sectionsec:sec:introduction
Figurefig:fig:overview
Tabletab:tab:results
Equationeq:eq:loss
Algorithmalg:alg:training
Why do prefixes matter? In a large paper with dozens of labels, \ref{x} alone tells you nothing about what is being referenced. Prefixes drastically improve readability and maintainability.
Common mistake: \label must come after \caption to capture the right number. If \label is placed before \caption, the reference will resolve to the wrong number.

See it work

Give the sub-subsection from Section 6 a label, then refer to it from the text:

\subsubsection{Drilled Down}
\label{subsubsec:drilled-down}
...
As described in Section~\ref{subsubsec:drilled-down}, ...

Labels never appear in the PDF — they are names for you and your co-authors. The same mechanism works for figures, tables, equations and algorithms.

Splitting a paper into sub-files

Long papers are easier to manage, and to write together, when each section lives in its own file.

Create a new file

In the file tree, choose New File and name it, for example intro.tex.

Write the section inside it

The sub-file holds only content — no \documentclass and no \begin{document}.

Pull it into the main file

Where the section should appear in main.tex, write \input{intro} (the .tex extension is optional).

\begin{document}
\maketitle
\input{intro}      % contents of intro.tex appear here
\input{method}
\end{document}

08 Figure

Inserting figures — built up one step at a time, the way you would actually do it.

Call \includegraphics — and watch it fail

\includegraphics{file} inserts an image file (path relative to the project). Try it in a plain document:

\documentclass{article}
\begin{document}
\section{More stuff}
Insert a figure in this section.
\includegraphics{overview.pdf}
\end{document}

Load graphicx in the preamble

Images need the graphicx package, loaded before \begin{document}:

\documentclass{article}
\usepackage{graphicx}   % must come before \begin{document}
\begin{document}
...

Wrap it in a figure environment

A bare image sits in the text like a giant letter and may not fit the page. Wrapping it in figure makes it a float: LaTeX moves it to a good position, and you can add a caption.

\begin{figure}
  \includegraphics{overview.pdf}
\end{figure}

Center, size, caption, label — then refer to it

\begin{figure}[t]
  \centering
  \includegraphics[width=0.8\linewidth]{figures/overview.pdf}
  \caption{Overview of our TDA pipeline.}
  \label{fig:overview}          % always after \caption
\end{figure}

As shown in Figure~\ref{fig:overview}, ...
Use vector images. PNG and JPEG are raster images and blur when zoomed. Export plots and diagrams as PDF so they stay sharp at any size.

Position Options

The optional argument after \begin{figure} tells LaTeX where it may place the float.

OptionMeaning
hhere — if possible, at this point in the text
ttop of the page — the most stable choice for papers
bbottom of the page
pon a dedicated float page
!override LaTeX's internal constraints, e.g. [!t]
Hexactly here (requires the float package)

Options combine: [ht] for drafts, [tb] to allow top or bottom, [htbp] for maximum flexibility. For example, [b]:

\begin{figure}[b]
  \includegraphics{overview.pdf}
\end{figure}

Sizing the image

OptionEffect
width=\linewidthWidth of the current column (0.5\linewidth is half)
width=\textwidthWidth of the whole text block
height=5cmFixed height
scale=0.7Scale by a factor
keepaspectratioKeep proportions when both width and height are set

Two-Column-Spanning Figures (two-column layout)

In a two-column paper, an architecture diagram squeezed into one column is often unreadable. figure* spans both columns (it can only go at the top or on a float page):

\begin{figure*}[t]     % figure* instead of figure
  \centering
  \includegraphics[width=\textwidth]{wide.pdf}
  \caption{Two-column-spanning figure.}
  \label{fig:wide}
\end{figure*}

Caption style

With \usepackage{caption} you can tune captions globally: \captionsetup{font=small, labelfont=bf, skip=5pt} gives smaller text, a bold “Figure 1” and a 5pt gap between image and caption. Venue templates usually set this already — don't override them.

09 Table

The table (float) plus tabular (content) combination, one piece at a time.

Start with tabular

tabular holds the cells. Its argument declares the columns, one letter per column. Cells are separated by &, and rows end with \\.

Wrap it in table

\begin{table}
  \begin{tabular}{...}
  ...
  \end{tabular}
\end{table}

Center it

Add \centering as the first line inside table.

Add a rule

\hline draws a horizontal line.

Fill in the cells

\begin{table}
\centering
\begin{tabular}{lccc} \hline
Head 1 & Head 2 & Head 3 & Head 4 \\
1      & 2      & 3      & 4      \\ \hline
\end{tabular}
\end{table}

Vertical lines (optional)

Put | between column letters, e.g. {l|c|c|c}. Most paper templates avoid vertical rules, so use them sparingly.

A paper-ready table

Like figures, tables take \caption and \label. In tables the caption conventionally goes above:

Code 
\begin{table}[t]
  \centering
  \caption{Comparison.}
  \label{tab:result}
  \begin{tabular}{lcc}
    \hline
    Method & Acc. & F1 \\
    \hline
    Baseline & 82.1 & 0.79 \\
    Ours     & 89.4 & 0.87 \\
    \hline
  \end{tabular}
\end{table}
Preview

Table 1. Comparison.

MethodAcc.F1
Baseline82.10.79
Ours89.40.87

Column Specifiers

SpecifierEffect
l / c / rLeft / centered / right-aligned
p{3cm}Fixed width with automatic line breaks (top-aligned)
m{3cm} / b{3cm}Fixed width, vertically centered / bottom-aligned (needs array)

For cleaner tables, use the booktabs package and its \toprule, \midrule, \bottomrule rules instead of \hline. To build a table visually, try Tables Generator.

10 Equation

Mathematics — the area where LaTeX shines brightest.

Inline Math

Math inside a sentence goes between two dollar signs:

The variable is set to $x = 3$ before the loop.

Display Math (numbered)

A standalone, numbered equation uses the equation environment. Give it a label so you can refer to it with \eqref{eq:emc}:

\begin{equation} \label{eq:emc}
E = mc^{2}
\end{equation}

Display Math (unnumbered)

If you never refer to it, drop the number with the short form:

\[
E = mc^{2}
\]

Align Environment (multi-line)

Code 
\begin{align}
  a &= b + c \\
    &= d + e + f
\end{align}
Preview
$$\begin{aligned} a &= b + c \\ &= d + e + f \end{aligned}$$

& marks the alignment point (usually just before =), and \\ starts a new line.

Required package: \usepackage{amsmath} — needed for align, gather, cases and \eqref. For a full symbol reference, see an online LaTeX math cheat sheet.

12 Citations with BibTeX

Keep references in a .bib file and let LaTeX number and format them.

Create a .bib file

Add a new file to the project, e.g. refs.bib. It holds one entry per paper you cite.

Copy the BibTeX entry from Google Scholar

On Google Scholar, click Cite under the paper, then BibTeX.

@article{vaswani2017attention,
  title={Attention is all you need},
  author={Vaswani, Ashish and Shazeer, Noam and Parmar, Niki and others},
  journal={Advances in neural information processing systems},
  volume={30},
  year={2017}
}

Paste it into refs.bib

The first field (vaswani2017attention) is the key you cite with. You may shorten it, e.g. to vaswani2017.

Point the document at the file

At the end of the body, choose a style and name the .bib file (without the extension). Keep this order:

\bibliographystyle{plain}
\bibliography{refs}

Cite in the text

Transformers~\cite{vaswani2017attention} replaced recurrence with attention.
Never type references by hand. Cite through the .bib file so numbering, ordering and formatting stay consistent.

13 Algorithm

Pseudocode blocks, common in engineering papers.

An algorithm uses two nested environments from two packages, both loaded in the preamble:

EnvironmentRole
algorithmThe float: caption, number and placement (like figure)
algorithmicThe pseudocode itself: \IF, \FOR, \REQUIRE, …
 
\usepackage{algorithm}
\usepackage{algorithmic}
...
\begin{algorithm}[t]
\caption{My First Simple Algorithm}
\label{alg:first}
\begin{algorithmic}[1]      % [1] = number every line
\REQUIRE Input value $i$
\ENSURE Output value $x$
\STATE $x \leftarrow 2$
\IF{$i \ge 2$}
    \STATE $x \leftarrow x + 1$
\ELSE
    \RETURN $x$
\ENDIF
\end{algorithmic}
\end{algorithm}

Commands

CommandMeaning
\REQUIRE / \ENSUREInput / output
\STATEOne statement
\IF{…} \ELSE \ENDIFConditional
\FOR{$i=1$ to $N$} … \ENDFORFor loop
\WHILE{…} … \ENDWHILEWhile loop
\RETURNReturn a value
[1] / [0]Show / hide line numbers

🚨 Common Beginner Mistakes

  • Incorrect label position — placing \label before \caption causes the wrong number to be referenced.
  • Missing begin/end pairs — mismatched environments cause compilation failures.
  • Missing packages — always include amsmath, graphicx, and hyperref by default.
  • Math-mode errors — do not use _ or ^ outside of math mode.
  • Figure path errors — set the directory once with \graphicspath{ {./figures/} }.
  • Korean character issues — use the kotex package (pdfLaTeX) or XeLaTeX with kotex.

✅ Paper-Writing Best Practices

  • Figure-first principle: sketch your figures before writing prose, then write to support them.
  • Self-contained captions: the caption alone should explain the figure.
  • Meaningful label naming: use semantic names like fig:tda-pipeline — never fig:1.
  • Version control: split content across main.tex and sections/*.tex, and track everything with git.
  • Bibliography: keep references in a separate .bib file — use Google Scholar's BibTeX export.
  • Overleaf collaboration: use track changes and inline comments aggressively.
