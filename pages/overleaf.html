01 Overleaf 소개

LaTeX와 Overleaf의 정체 — 그리고 왜 학계에서 이걸 쓰는지.

LaTeX란?

LaTeX는 도널드 커누스의 TeX 시스템을 기반으로 한 전문 조판 언어입니다. Word 같은 WYSIWYG 에디터가 아니라, 마크업 언어로 문서 구조를 정의하면 컴파일러가 PDF를 생성합니다.

Overleaf란?

Overleaf는 클라우드 기반 협업형 LaTeX 에디터입니다. 설치 없이 브라우저에서 바로 작성·컴파일·공동 편집이 가능합니다. overleaf.com

컴파일 흐름

사용자 코드 (.tex) │ ▼ LaTeX Compiler (pdfLaTeX / XeLaTeX / LuaLaTeX) │ ▼ PDF Output
왜 LaTeX인가? 수식 품질이 압도적이고, 참조·번호 매김·서지가 자동화되며, 출력이 일관됩니다. 학회·저널 템플릿이 대부분 LaTeX 기반이므로 학계 표준입니다.

03 문서의 시작과 끝

Preamble과 Document body — LaTeX 문서의 뼈대.

% --- Preamble (설정 영역) ---
\documentclass{article}
\usepackage{graphicx}     % 그림 삽입
\usepackage{amsmath}      % 수식 환경
\usepackage{hyperref}     % 하이퍼링크 / 참조

% --- Document Body (실제 내용) ---
\begin{document}

  % 여기에 본문 작성

\end{document}
Preamble은 출력되지 않습니다. 클래스·패키지·매크로·메타데이터를 정의하는 곳입니다. 본문은 반드시 \begin{document}와 \end{document} 사이에 작성합니다.

문서 구조 시각화

Preamble (설정) │ \documentclass{...} │ \usepackage{...} │ \title{...} ▼ \begin{document} │ \maketitle │ \begin{abstract}...\end{abstract} │ \section{Introduction} │ ... ▼ \end{document}

05 Abstract

논문 전체를 한 문단으로 요약하는 핵심.

Code 
\begin{abstract}
We apply Topological Data Analysis (TDA)
to BRCA breast cancer datasets to discover
novel topological structures and biomarkers.
Our results show that persistence-based
features outperform conventional baselines
in subtype classification.
\end{abstract}
Preview

Abstract

We apply Topological Data Analysis (TDA) to BRCA breast cancer datasets to discover novel topological structures and biomarkers. Our results show that persistence-based features outperform conventional baselines in subtype classification.

좋은 Abstract 구조 (CARS): Context → Aim → Result → Significance. 보통 150–250단어, 단일 문단.

07 Label & Reference

문서 내부 자동 참조 — 가장 강력한 LaTeX의 강점.

\section{Introduction}\label{sec:intro}

As shown in Section \ref{sec:method}, ...

See Figure \ref{fig:overview} and Equation \eqref{eq:main}.

Label Prefix Convention

타입Prefix예시
Sectionsec:sec:introduction
Figurefig:fig:overview
Tabletab:tab:results
Equationeq:eq:loss
Algorithmalg:alg:training
왜 Prefix가 중요한가? 큰 논문에서 label이 수십 개 생기면 \ref{x}만 보고는 무엇인지 알 수 없습니다. Prefix를 두면 가독성과 유지보수성이 비약적으로 향상됩니다.
흔한 실수: \caption 다음에 \label을 놓아야 번호가 정확히 잡힙니다. \label이 caption보다 위에 있으면 잘못된 번호를 참조합니다.

+ Tips · Mistakes · Templates

📑 추천 논문 템플릿

IEEE ACM CVPR NeurIPS ICML ICLR Springer LNCS

🚨 초보자가 자주 하는 실수

  • label 위치 오류 — caption 위에 label을 두면 잘못된 번호 참조
  • begin/end 누락 — 환경 짝이 맞지 않으면 컴파일 실패
  • package 누락 — amsmath, graphicx, hyperref는 기본 추가 권장
  • math mode 오류 — 수식 밖에서 _ 또는 ^ 사용 금지
  • figure path 오류 — \graphicspath{ {./figures/} }로 디렉토리 지정 권장
  • 한글 깨짐 — kotex(pdfLaTeX) 또는 XeLaTeX + kotex 사용

✅ 논문 작성 Best Practice

  • Figure first principle: 본문보다 figure를 먼저 그려보고, 그것에 맞춰 글을 쓴다
  • Caption은 self-contained: 캡션만 보고도 그림을 이해할 수 있게 작성
  • Label naming: fig:tda-pipeline처럼 의미가 드러나게 — 절대 fig:1 같은 임의 이름 금지
  • 버전 관리: main.tex 외에 sections/*.tex로 분리하고 git 관리
  • 참고문헌: .bib 파일로 분리 — Google Scholar의 BibTeX 인용 활용
  • Overleaf 협업: track changes, comments 적극 활용
